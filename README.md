# FollowGuard — X Following Cleanup Assistant

اکستنشن کروم برای بررسی و پاک‌سازی لیست Following در X/Twitter.

> V2 با رویکرد **Scan → Analyze → Review → Execute** طراحی می‌شود تا قبل از هر تغییر، کاربر بتواند کاندیدها و دلایل انتخاب آن‌ها را بررسی کند.

## وضعیت V2

- Branch توسعه: `upgrade/v2-followguard`
- مرحله فعلی: طراحی و پیاده‌سازی تدریجی
- تمرکز: اسکن خواندنی، امتیازدهی، فیلتر و بررسی دستی قبل از هر اقدام

## نصب

1. این پوشه را دریافت کن.
2. برو به `chrome://extensions`
3. **Developer mode** را روشن کن.
4. **Load unpacked** را بزن و پوشه پروژه را انتخاب کن.

## هدف V2

نسخه فعلی پروژه بر اساس یک heuristic ساده مثل نبود Bio تصمیم می‌گیرد. در V2 ابتدا اطلاعات قابل مشاهده پروفایل‌ها جمع‌آوری می‌شود و هر حساب با چند سیگنال امتیاز می‌گیرد؛ سپس کاربر می‌تواند کاندیدها را ببیند و انتخاب کند.

### اصول طراحی

- Read-first: اسکن اولیه بدون ایجاد تغییر در Following
- Candidate scoring: امتیاز ۰ تا ۱۰۰ همراه با دلیل
- Review before action: هیچ تغییری بدون تأیید کاربر انجام نشود
- Local-only: بدون سرور خارجی و بدون ارسال داده‌های Following
- Robust DOM handling: مقاوم‌تر در برابر تغییرات UI در X
- Persistent settings: ذخیره تنظیمات در `chrome.storage`
- History: ثبت نتیجه عملیات برای قابلیت بررسی بعدی

## امنیت

اکستنشن نباید پسورد، کوکی، توکن یا اطلاعات حساب را به سرویس خارجی ارسال کند. قبل از استفاده از هر قابلیت تغییردهنده، ریسک‌های محدودیت و قوانین X را در نظر بگیر.

## توسعه

نسخه V2 ابتدا با **Scan/Review** ساخته و تست می‌شود؛ قابلیت‌های تغییردهنده فقط بعد از پایدار شدن بخش تحلیل و با تأیید صریح کاربر بررسی خواهند شد.
