# Twitter / X Inactive Unfollower

اکستنشن کروم برای آنفالو کردن خودکار اکانت‌های احتمالاً غیرفعال از لیست فالوینگ توییتر/ایکس.

## نصب

1. این پوشه رو extract کن
2. برو به `chrome://extensions`
3. **Developer mode** رو روشن کن (گوشه بالا راست)
4. **Load unpacked** رو بزن و این پوشه رو انتخاب کن

## استفاده

1. لاگین کن و برو به `x.com/نام‌کاربری‌خودت/following`
2. روی آیکون اکستنشن کلیک کن
3. بخش ریسک‌ها رو بخون و تیک تاییدش رو بزن
4. تنظیمات (تیک آبی، بیودار، تاخیر) رو انتخاب کن
5. **شروع** رو بزن

---

## 🔒 امنیت و دسترسی اکانت — حتماً بخون

### این اکستنشن چطور کار می‌کنه؟

هیچ API رسمی توییتر/ایکس استفاده نمی‌شه. اکستنشن مستقیماً روی صفحه‌ی فالوینگت در مرورگرت اجرا می‌شه، پروفایل‌ها رو می‌خونه (DOM scraping) و **روی دکمه‌ی "Following" واقعی کلیک می‌کنه** — دقیقاً همون کاری که خودت با دست انجام می‌دادی، فقط خودکار.

### ریسک‌های واقعی

| ریسک | توضیح |
|---|---|
| **محدودیت موقت اکانت** | X الگوهای کلیک سریع و پشت‌سرهم رو رفتار بات تشخیص می‌ده. ممکنه پیام "action blocked" بگیری یا موقتاً نتونی فالو/آنفالو کنی. |
| **قفل شدن اکانت** | در موارد شدید (تعداد زیاد آنفالو در زمان کوتاه)، X ممکنه از تو کد تایید یا شماره موبایل بخواد. |
| **نقض قوانین استفاده (ToS)** | اتوماسیون اکشن‌های کاربری، حتی بدون API، معمولاً برخلاف قوانین استفاده‌ی پلتفرمه. مسئولیت استفاده از این ابزار با خودته. |
| **برگشت‌ناپذیری** | آنفالوها فوری اعمال می‌شن. این اکستنشن لیست افرادی که آنفالو کرده رو **ذخیره نمی‌کنه**، پس نمی‌تونی به‌صورت خودکار برگردونیشون. |
| **دقت تشخیص "غیرفعال"** | چون به API رسمی دسترسی نداریم، معیار فعلی فقط "نداشتن بیو" هست — این یه حدس تقریبیه، نه تشخیص دقیق بر اساس آخرین فعالیت. ممکنه اکانت‌های فعالِ بدون بیو هم آنفالو بشن. |

### چی امنه و قابل بررسیه

- **بدون سرور خارجی:** کل کد فقط ۴ فایل ساده‌ست (`manifest.json`, `content.js`, `popup.js`, `popup.html`). هیچ `fetch` یا درخواست به دامنه‌ی خارجی وجود نداره — می‌تونی خودت یا هرکسی که بلده، کد رو بخونه و تایید کنه.
- **بدون جمع‌آوری داده:** هیچ اطلاعاتی (یوزرنیم، لیست فالوینگ، توکن، کوکی) جمع‌آوری، ذخیره یا ارسال نمی‌شه.
- **بدون نیاز به پسورد:** اکستنشن از سشن لاگین خودت در مرورگر استفاده می‌کنه؛ هیچ پسورد یا کلید API ازت نمی‌خواد.
- **Permission محدود:** فقط به `x.com` و `twitter.com` دسترسی داره (`host_permissions`)، نه کل اینترنت.

### توصیه‌های ایمنی برای استفاده

- تاخیر رو حداقل **۳-۵ ثانیه** بزار، به‌خصوص اگه لیست فالوینگ بزرگیه.
- در یک نشست بیش از **۵۰-۱۰۰ آنفالو** انجام نده؛ بعد چند ساعت صبر کن.
- اگه پیام خطا یا محدودیت از طرف X دیدی، **فوری متوقفش کن** (دکمه توقف) و چند ساعت صبر کن.
- این کار رو روی اکانت‌های خیلی مهم یا تجاری با احتیاط بیشتری انجام بده.

## محدودیت فنی

چون به Twitter API دسترسی نداریم، معیار "غیرفعال بودن" دقیق نیست (فقط نبود بیو). برای تشخیص دقیق‌تر بر اساس **تاریخ آخرین توییت**، باید از Twitter API رسمی (با کلید توسعه‌دهنده) استفاده بشه که نسخه‌ی دیگه‌ای از این ابزار می‌تونه باشه.
